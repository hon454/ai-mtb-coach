# 다음 강습 자료 요청 목록

분석하다 막힌 부분을 풀려면 어떤 자료가 더 필요한지 정리한 목록. 새로 필요한 게 생기면 여기에 추가하고, 받은 자료는 "받음"으로 옮긴다.
우선순위: ★★★ 지금 분석이 막혀 있음 / ★★ 정확도가 크게 오름 / ★ 있으면 좋음.

## 강습 현장에서 (촬영)

| 우선 | 무엇을 | 어떻게 | 왜 (지금 막힌 것) |
|---|---|---|---|
| ★★★ | 좌회전 뱅크를 **높은 자리**에서 찍은 주행 1~2회 | 지금 촬영 자리 근처에서 가슴~머리 위 높이로 들거나, 언덕 위쪽에서. 뱅크 벽 아래 끝(바닥과 만나는 곳)까지 화면에 들어오게. | 지금 각도에서는 정점 부근에서 바퀴 아래가 앞 흙 능선에 가려 벽의 어느 높이를 타는지 잴 수 없음(LOG 뱅크 인식 항목). |
| ★★ | 같은 뱅크를 **옆(바깥쪽)**에서 찍은 주행 1회 | 뱅크 벽 정면이 보이는 자리. 핸드헬드로 따라가도 됨. | 뒷모습만 있으면 2D 상체각에 앞으로 숙인 정도가 섞임. 옆모습이 있어야 자세 높이·상체 숙임을 따로 잴 수 있음. 앞뒤 무게중심(BB보다 앞인지 뒤인지)도 뒷모습에서는 카메라 깊이 방향이라 잴 수 없음. |
| ★★ | **기준 길이** 1개 | 뱅크 근처 고정물(나무의 주황 테이프, 말뚝 등)의 길이를 줄자로 재서 메모하거나, 길이를 아는 물건(자전거를 세워 둔 사진도 됨)을 벽 앞에 두고 한 장. | 지금은 모든 거리가 픽셀이라 런끼리만 비교 가능. 실제 cm로 바꾸고 다른 날·다른 카메라와 비교하려면 필요. |
| ★★ | 매주 **같은 자리·같은 높이**에서 촬영 | 오늘(11/21) 런 1~5·7을 찍은 자리를 기준으로. 자리를 표시해 두면 좋음. | 주별 비교는 같은 카메라 자리일 때만 숫자로 가능. 런6처럼 자리가 다르면 비교에서 빠짐. |
| ★★ | 핸들바에 **폰을 달고** 좌회전 뱅크 주행 1회 | 스템·핸들 마운트에 폰을 고정하고 센서 기록 앱(가속도·자이로, 100Hz 이상)을 켠 채 탄다. 같은 주행을 평소처럼 촬영도 한다. | 자전거 기울기의 정답이 없어 실루엣(bike_fit)과 3D 손·발(GVHMR) 중 어느 쪽이 맞는지 모름. 둘이 옆모습에서 20~40° 다름. 폰 yaw로 진행 방향도 얻어 GVHMR 각도의 진행 방향 오차(15°당 약 10°)를 없앨 수 있음. |
| ★ | 촬영할 때 **줌 배율** 메모 | 1x/2x/3x 등 폰 화면의 배율. | GVHMR에 초점거리가 필요함. 지금은 영상으로 추정(35mm 환산 약 100mm). 배율을 알면 확인할 수 있음. |
| ★ | 프레임 레이트 **60fps** 이상 | 폰 카메라 설정. 카톡으로 보내면 화질이 떨어지므로 원본은 다른 방법(드라이브 등)으로. | 뱅크 통과가 2초 정도라 30fps면 장면이 60장뿐. 기울기 변화 타이밍을 더 촘촘히 볼 수 있음. |
| ★ | **원본 화질** 영상 | 카톡 "원본으로 보내기", 또는 클라우드 공유. | 압축 때문에 자전거 마스크 경계가 흐려지고, 그림자와 섞이는 프레임이 생김. |
